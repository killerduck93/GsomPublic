Privacy Policy — GSOM FLOW BETA

Last updated: 2026-09-21 · Product version 0.9.0

Who we are

GSOM FLOW is an independent student dashboard Chrome extension. It is not affiliated with, endorsed by, or officially connected to POLIMI Graduate School of Management or Politecnico di Milano.

Single purpose

Display academic data available in the authenticated student’s FLOW browser session in a single local dashboard.

What the extension accesses

When you are already logged in to GSOM FLOW in Chrome (https://www.gsom.polimi.it), the extension reads Flow API responses available to your browser session for courses, calendar/lessons, clips, assignments, attendance-related calendar events, and document metadata.

Access uses the browser’s existing authenticated session. The extension does not ask for a password and does not use chrome.cookies or read cookie values.

Where processing happens

All processing happens locally in your browser (extension service worker and dashboard pages).

What is stored locally

Using chrome.storage.local, the extension may store a short-lived dashboard cache/view-model, a minimized change-detection snapshot (entity IDs/fingerprints and timestamps), and lightweight collection metadata.

The extension does not intentionally store cookies, authentication tokens, Authorization headers, passwords, or full raw API payloads.

What is NOT collected by the developer

  • No data is sent to the developer.
  • No analytics, advertising, or telemetry SDKs are included.
  • No remote logging backend is operated by this extension.
  • No account is created with the developer.

Network requests made by the extension go only to https://www.gsom.polimi.it to fetch your Flow data for local display.

Permissions explained

Data deletion

Remove the extension from Chrome, or clear the extension’s storage via Chrome’s extension details / site data controls.

Children’s privacy

This extension is intended for adult students of a graduate / executive program. It is not directed at children.

Changes

If this policy changes materially, the version in the extension package / Store listing will be updated.

Contact

Use the support email published in the Chrome Web Store listing for GSOM FLOW BETA.
